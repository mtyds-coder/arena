小球竞技场更新日志

记录小球竞技场的版本迭代与主要功能演进。当前主版本为 m1.3.2-patch.1（房间列表联机版）；每个版本均保留为独立文件，便于对照查看。

m1.3.2-patch.1

最新版联机版
  • 新增「房间列表」联机：房主开房后，房客在列表里点「加入」即自动完成握手，不再需要互发配对码；连不上时可退回复制粘贴配对码。
  • 房间列表改走公共 MQTT（默认 wss://broker.emqx.io:8084/mqtt，页面内嵌精简 MQTT 客户端，不引第三方库）：房主把「房间名 + offer」以 retained 消息发到 arena/rooms/房间号，房客订阅 arena/rooms/+ 即可立刻看到所有房间；房客把 answer 发到 arena/ans/房间号。无需注册、无需部署服务器。
  • 公共 broker 自动切换：内置 broker.emqx.io → broker.hivemq.com → test.mosquitto.org 三个地址，某个连不上（6 秒内没有 CONNACK 或直接报错）就自动换下一个，并记住上次成功的那个。手填其它地址时只试手填的。之所以要这个，是因为公共测试服务器经常抽风/按 IP 限流。
  • STUN 改为国内可访问的 stun.miwifi.com:3478（原来的 Google / Cloudflare STUN 在国内常被阻断）。
  • 房主关房或断开时发一条空 retained 消息把房间从列表里抹掉，并复位到单机模式。
  • cloudflare-worker.js 仍保留在仓库里，作为「有自己域名、绑定到 Workers 后使用」的备选方案（workers.dev 在国内被 DNS 污染，无法直接用）。
  • 本地文件（file://）打开时自动识别：浏览器会禁止这类页面建立 WebSocket，所以联机面板会直接显示黄色提示、折叠 MQTT 房间列表区，并把「我是房主/我是房客（手动）」提升为主按钮，避免误以为房间列表坏了。
  • 新增 serve.ps1：零依赖的 PowerShell 静态服务器（不需要管理员权限），在电脑上运行后 iPad/手机可用 http://局域网IP:端口/ 打开页面，从而让房间列表（WebSocket）正常工作。
  • 另存一份纯英文文件名的副本 arena-m1.3.2-patch.1.html（内容与本版完全一致，仅文件名不同），方便上传到 GitHub Pages 等静态托管后直接用 URL 打开（中文文件名会被编码成很长的 %XX 串）。所有历史版本也各生成了一份同规律的英文名副本（arena-v1.0.0.html … arena-v1.3.2.html、arena-m1.3.2.html，更新日志为 arena-changelog.html 且内部链接已改写），并生成了 index.html 版本索引首页（按版本倒序列出全部 19 个可玩版本，说明文字自动取自本日志的第一条）。
  • 房间存活机制：房主开房期间每 60 秒重发一次 retained 消息当心跳，房客端只显示 3 分钟内还有心跳的房间，每 15 秒自动重画列表。这样即使房主直接关掉标签页（没点「断开连接」），僵尸房间也会在 3 分钟内自动从列表里消失，不会点进去连不上。
  • MQTT 断线自动重连：按 2s → 4s → 8s → 15s → 30s 退避重试，状态栏显示「N 秒后自动重连（第 K 次）」；重连成功后如果是房主，会把房间重新挂回列表并重新订阅应答主题。点「断开连接」会停止重连（不会在后台一直重试）。
  • 连接状态显示改为带计时与诊断：connecting 时显示「正在建立连接…（N 秒）」并每秒刷新；超过 15 秒自动给出打洞失败提示，并列出本机候选统计（host / 公网 srflx / 中继 relay）。若本机没有 srflx 候选，直接提示「双方不在同一局域网时基本连不上（STUN 可能被墙）」；若双方都是严格 NAT，则提示需要 TURN 中继。连接成功时也会显示本机候选统计，方便判断这次是靠内网还是靠公网连上的。
  • 修复联机握手的致命 bug：连接成功（connectionState === 'connected' 与数据通道 onopen）时调用的是未定义的 onNetConnected()，正确函数名是 netOnConnected()。这个拼写错误会导致握手回调抛异常、「角色/开始状态同步」与房客的 hello 请求从未发出（表现为连上了但房客端迟迟不同步）。
  • 修复房客端「切换角色后名字不更新」：netApplyState 只同步了角色下标（球和血条会变），但没有调用 syncTopNames()，导致顶部名字一直是旧角色。现在检测到角色变化就同步名字与颜色。
  • 修复房客端「未开局时船锚全堆在左上角」：房主没开局时锚的 ax/ay 还是 undefined，快照里写成 r1(h.ax || 0) 被转成 0 发给房客，房客就画在 (0,0)。现在未定位时发 null，房客端按球的位置推算（房主本地一直是对的，所以房主看不到这个问题）。
  • 联机面板新增「当前房间」状态条：房主开房后显示「🟢 你是房主 · 房间「房间名」· 房间号 xxxxxx」（青色），房客加入后显示「🔵 你是房客 · 房间「房间名」· 房间号 xxxxxx」（紫色），关房/断开后恢复为灰色的「未加入房间」。

m1.3.2

上一版本联机版
  • 新增「局域网联机」（仅 1v1）：控制栏加「联机」按钮，房主与房客互发一段复制粘贴的邀请码/应答码即可建立点对点连接，无服务器、无外网。
  • 联机架构为房主权威：房主跑物理并以 30Hz 推送状态，房客只负责渲染；房客可选粉方角色，开始与终止由房主控制。
  • 联机时改为手动操作：点击画布朝指针方向释放技能（仍受冷却限制），船锚朝向实时跟随指针，幽灵与医者改为点击进入累计阶段。
  • 手机/平板适配：长按拖动即可当鼠标指针用，对局中锁定页面滚动与缩放。
  • 修复断开联机后按钮卡死：此前断开时联机状态没复位，房客端开始按钮一直显示「等房主开始」且连同延时/2v2/BOSS 战共 4 个按钮全部不可点。现在断开（或连接失败、手动点「断开连接」）都会切回单机模式、恢复全部按钮、解除页面锁定并结束进行中的对局。
